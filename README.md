# OpenFire

A full-stack Node.js application built with Express, MongoDB Atlas, EJS, and Tailwind CSS.

## Features
- Contact/Enquiry form
- MongoDB Atlas integration
- Admin data view (EJS)
- Tailwind CSS styling
- Latest enquiries shown first

## Tech Stack
- Node.js
- Express.js
- MongoDB Atlas
- EJS
- Tailwind CSS

## Setup
```bash
npm install
npm run dev
